## 📖 Overview

**Dummy Portfolio** is a personal portfolio template built with HTML, CSS, and JavaScript. It's designed to showcase your skills, projects, and professional experience in a clean, responsive layout.

> 🎯 **Purpose:** Portfolio template for developers and designers

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📱 **Responsive Design** | Works on all device sizes |
| 🎨 **Clean UI** | Modern, minimalist design |
| ⚡ **Fast Loading** | Pure HTML/CSS/JS - no frameworks needed |
| 📄 **Multiple Sections** | About, Projects, Skills, Contact |
| 🔗 **Social Links** | LinkedIn, GitHub, and other profiles |
